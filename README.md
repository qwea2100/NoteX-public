## 專案簡介

本專案是一個教育內容電商平台，讓學生與教師能夠自由買賣、分享優質筆記與教材，以極低成本快速驗證「教育內容交易」這個市場假設。專案於青年發展署 U-start 創業計畫中，獲評為**績優團隊**。

在專案中，我擔任產品企劃角色，主責整體產品規劃、需求驗證、規格定義，並與開發團隊協作將構想落地為可運作的 MVP。

## 關於此 Repo

收錄專案中的產品規格文件，用以展示從問題定義、使用者情境分析，到規格邏輯設計與取捨判斷的完整產品思考過程。**此 repo 為規格文件展示，非原始碼呈現。**
