# 點數購物車：用免費點數筆記解決冷啟動推廣

> 相關文件：[雙軌購物車設計](dual-track-cart.md)、[活動 QR 兌換與 LINE 綁定](line-claim-flow.md)、[問題與使用者](../overview/problem-and-users.md)｜[← 返回文件導覽](../README.md)

## 一句話說明

與行銷團隊共同決議，設計並主導開發「會員以點數兌換免費筆記」機制，讓平台能用免費內容導流，並與現金購買並行。

## 1. 問題與使用者

- **問題：只有付費筆記，行銷端很難推廣。** 問卷也顯示，沒有免費筆記，使用者很難步入平台試用。
- **使用者**：想低門檻試讀的會員、需要推廣工具的行銷團隊、講者的現場聽眾。

## 2. 產品決策

- **用「點數兌換」，而不是直接開放免費下載**：不使用折扣碼的原因是因為比起直接免費取得，會員透過日常累積的點數換取心儀的筆記比較能推廣日常登入，目標是提升會員黏著度。
- **新會員註冊贈送 50 點**：降低第一次兌換的門檻、期望帶來回訪。
- **點數兌換筆記與付費筆記為完全不互通的商品，點數不能折抵現金**：降低營運設定成本。
- **在商品後台逐一勾選「允許用點數付款」**：只有被勾選的筆記會出現在點數兌換區，提供賣家更多銷售方案安排。
- **預先留下「現金與點數兩區並列，結帳時分開處理」的設計空間**：詳見 [雙軌購物車設計](dual-track-cart.md)。
- **兌換也走訂單流程，建立 0 元訂單並自動完成**：留下完整紀錄，才能分析導流成效。
- **延後的項目**：擴充更多金流方式，資源優先投入免費點數筆記與活動兌換。


## 3. AI 怎麼用

- 以 WooCommerce 與 myCred（點數系統）為基礎，由 Claude Code 協作實作。
- 我負責：兌換規則與情境的定義、混合購物車等邊界案例的驗收、發現問題後的修正方向。

## 4. 成果

- **已驗證**：核心流程可完整跑通，免費筆記和付費筆記容易區分。
- **觀察**：使用者在使用免費筆記時會完整體驗到一本筆記的閱讀歷程、筆記標記效果，有收到體驗回饋，據此調整了標記效果的顯示方式。

## 5. 下一步

- 讓更多推廣筆記可以不同型態發送，例如連結貼文、QR code 等，讓更多使用者接觸到平台。
